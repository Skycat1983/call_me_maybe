# Template: Thematic Topic

Copy this template into the relevant theme and remove sections that do not
help that topic.

```markdown
# Topic Title

- Kind: Thematic talking point
- Theme: Theme name
- Depth: Overview, applied, or detailed
- Status: Living
- Last reviewed: YYYY-MM-DD
- Prerequisites: Named documents or none

## Why this matters

The learner's reason for understanding the topic.

## Surface explanation

The shortest accurate mental model.

## Concepts and theory

General explanation independent of this project.

## Application in this project

Concrete files, variables, data, and decisions.

## Evidence and boundaries

Source facts, runtime observations, interpretations, requirements, and open
questions kept distinct.

## Discussion prompts

Questions for a voice agent to ask one at a time.

## Understanding checks

What the learner should be able to explain or trace.

## Likely misconceptions

Important distinctions.

## Related learning

Theme home, prerequisites, next depth, canonical references, relevant
waypoints, and source files.
```
