# Template: Waypoint Talking Points

Copy this template to `waypoints/NNN-short-theme.md` and replace instructional
placeholders. Do not link to this template as if it were a real waypoint.

```markdown
# Talking Points NNN: Title

Companion waypoint: path to chronological waypoint

## Agent preparation

Read the companion waypoint, relevant thematic guides, canonical references,
requirements, and source files.

## Short recap

What changed and why it mattered.

## Conversation order

1. First concept.
2. Evidence or experiment.
3. Decision and remaining question.

## Key evidence

Observed facts and their interpretation.

## Discussion prompts

Questions asked one at a time.

## Understanding checks

Concrete explanations the learner should be able to give.

## Likely misconceptions

Distinctions the agent should watch for.

## Related thematic learning

Current topic-centered guides relevant to this waypoint.

## Successful session outcome

What the learner should understand by the end.
```
