# Template: Theme Index

Copy this template to `themes/theme-name/index.md`. Create only reading routes
for documents that actually exist.

```markdown
# Theme: Human-Readable Name

- Kind: Thematic talking-point index
- Status: Living
- Last reviewed: YYYY-MM-DD

## Purpose

What this theme helps the learner understand.

## Choose a route

### Five-minute overview

Start with the overview document.

### Understand the theory

Read the concepts document.

### Apply it in this project

Read the project-application document.

### Study the detailed flow

Read the relevant deep-dive index.

## Current understanding

Brief summary of established facts and open areas.

## Voice-session guidance

How an agent should discuss this theme.

## Documents in this theme

Table of document, depth, purpose, and status.

## Related learning

Requirements, references, waypoints, neighboring themes, and source files.
```
