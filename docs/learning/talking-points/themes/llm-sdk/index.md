## Surface mental model

```text
Make target
    -> uv selects the project environment
    -> Python runs experiments/inspect_sdk.py
    -> the probe calls public Small_LLM_Model methods
    -> the SDK calls Transformers and PyTorch
    -> the probe reports returned values and observed behavior
```

The probe coordinates and reports an experiment. The SDK owns its public model
operations. Transformers and PyTorch perform the lower-level tokenization and
tensor computation.

## Current understanding

- The probe was written locally from the public SDK interface and project
  questions; it was not downloaded or generated by uv.
- Explicit CPU construction succeeded.
- The prompt encoded to an observed tensor shape of `(1, 11)`.
- Batched and one-sequence decoding returned different container shapes.
- The public getters located the tokenizer artifacts.
- The next-token call returned one observed vector of 151,936 logits.
- Logits are scores, not probabilities.
- Default automatic device loading remains a known issue; the explicit CPU
  route is available for learning experiments.

## Important boundary

The supplied SDK can be studied internally for learning, but application code
must use its public interface. The probe follows that restriction. It does not
yet implement constrained function calling, JSON generation, or Pydantic
validation.
